# Executive Synthesis — Public Portfolio Version

> Public-safe analytical summary. No patient-level data and no confidential Board material are included.

## Scope

- 200,000 clinical episodes in the supplied analytical workbooks
- 686,899,897.12 PLN billed base
- Four analytical pillars: clinical outcomes, operations/capacity, financial security, and SDOH/biomarkers

## Reconciled operational signals

- **18,076** no-shows across 200,000 appointments (**9.04%**).
- Remote cohort: **6,814 no-shows / 61,508 scheduled = 11.08%**.
- Severe scheduling-delay tier: **82,395 / 151,842 completed visits = 54.26%**.
- High-caseload clinicians: **708 / 1,000 = 70.8%**.

## Reconciled financial signals

- Billed base: **686,899,897.12 PLN**.
- Gross rejected claims: **202,829,853.72 PLN (29.53%)**.
- Prior-auth required: **6,686 / 83,977 = 7.96%** rejection rate.
- No prior-auth required: **9,310 / 116,023 = 8.02%** rejection rate.

## Interpretation

These are observational/descriptive evidence signals. They do not, by themselves, establish causality. Financial rejection is treated as gross rejected billing, not as a finalized irrecoverable write-off. Scenario values are modeled exposures, not guaranteed realized recovery.

## Analytical philosophy

The project separates:
`Question → Evidence → Validation → Analysis → Interpretation → Decision`

The objective is not to maximize the number of findings. It is to produce findings whose definitions, denominators, grain, evidence path, and limitations can be inspected.
