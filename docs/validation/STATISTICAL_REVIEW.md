# Statistical Review — File-Based

## Adherence comparison

Supplied Pillar 1 counts:
- High adherence: 1,329 crises / 33,475 patients = 3.9701%
- Low adherence: 1,359 crises / 31,941 patients = 4.2547%

An unadjusted two-sided pooled two-proportion z-test calculated from these supplied counts gives:
- z ≈ -1.833
- p ≈ 0.0668

Interpretation: the observed difference is not statistically significant at alpha=0.05 in this unadjusted comparison. This does not prove equivalence and does not address confounding.
